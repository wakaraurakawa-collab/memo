# 日記

メモ帳の `F5` のような打刻を、スマートフォンでもできる日記。

書いた内容は**この端末のブラウザの中だけ**に保存されます。どこにも送信しません。
ログインは不要で、開いてすぐ書けます。通信が切れていても使えます。

## 使い方

1. 開くと今日のページが出ます。そのまま書き始めてください。
2. 時刻を入れたいところで、画面下の **打刻** を押します。カーソルのある場所に入ります。
3. 書いた内容は自動で保存されます。保存ボタンはありません。

### 時刻の入れ方は4通り

| やり方 | 操作 |
|--------|------|
| 打刻ボタン | 画面下のボタンを押す。長押しで書式を選べる |
| 展開キーワード | 本文に `いま` と打つと `19:03` に変わる。`きょう` は日付になる |
| 自動打刻 | 改行を2回続けて新しい段落を始めると、行頭に時刻が入る(設定でオンにする) |
| キーボード | `F5` または `Ctrl` / `⌘` + `;`(PC 向け) |

展開キーワードで変換したい言葉が奪われるときは、**設定 → 展開キーワード**で書き換えるか削除してください。記号(`;t` など)に一括で切り替えることもできます。展開した直後なら、画面下の「取り消す」で元に戻せます。

### バックアップ

ブラウザのデータを消すと日記も消えます。**設定 → バックアップ**から Markdown か JSON で書き出して保管してください。JSON からは元に戻せます。

## 動かす

ビルドは要りません。静的ファイルをそのまま置けば動きます。

```sh
python3 -m http.server 8000
# http://localhost:8000 を開く
```

GitHub Pages に置く場合は、リポジトリの Settings → Pages で公開元のブランチを選ぶだけです。

iPhone では Safari で開き、共有ボタンから「ホーム画面に追加」しておくと、アプリのように起動できます。

## 構成

| ファイル | 中身 |
|----------|------|
| `index.html` | 画面の構造 |
| `styles.css` | 見た目。端末の標準書体のみを使い、外部から何も読み込みません |
| `app.js` | 全ての動作 |
| `docs/requirements.md` | 要件定義書 |

外部ライブラリは使っていません。

### 実装上の要点

- **本文テキストが唯一の正データ。** 打刻は本文中の文字列としてのみ存在し、別立ての記録は持ちません。後から本文を書き換えてもズレません。
- **打刻ボタンを押しても本文のフォーカスとカーソル位置が失われません。** これが崩れるとキーボードが閉じて打刻の意味がなくなるため、ポインタ操作の既定動作を抑止しています。
- **日本語入力の変換中は本文に触りません。** 未確定の状態で打刻を押した場合は、確定後に入ります。
- **文字の挿入には端末側の「取り消す」履歴を壊さない手段を使っています。** iPhone を振って取り消す操作もそのまま効きます。
